# Build Guide — EU AI Act Readiness Pack

**Created by School of AI**

1. Define the governed AI system.
2. Identify owner, users and affected populations.
3. Identify data, models, RAG, agents, tools and vendors.
4. Identify relevant jurisdictions and expert-review questions.
5. Create inherent-risk assessment.
6. Assign risk tier.
7. Select required controls.
8. Assign control owners.
9. Define control testing.
10. Define evidence.
11. Add independent review where appropriate.
12. Decide approval status.
13. Define remediation/exception process.
14. Define monitoring.
15. Define material-change triggers.
