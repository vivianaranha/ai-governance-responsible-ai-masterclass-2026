# Case Study 12 — Global AI Governance Program

**Created by School of AI**

**Domain:** Enterprise  
**Governance drivers:** inventory, jurisdictions, federated governance, assurance

## Assignment

1. Register the AI system.
2. Define system boundary and owner.
3. Identify affected populations.
4. Create inherent-risk assessment.
5. Assign risk tier.
6. Identify responsible-AI concerns.
7. Select required controls.
8. Define validation/testing evidence.
9. Map relevant framework/regulatory questions.
10. Define monitoring.
11. Define material-change triggers.
12. Make a governance decision.

## Mid-review twist

Choose one:
- model vendor changes behavior,
- new jurisdiction is added,
- fairness threshold fails,
- RAG source is poisoned,
- agent performs an unauthorized action,
- security discovers a third-party tool vulnerability,
- an AI incident becomes public.

Reassess the system and update the decision.
